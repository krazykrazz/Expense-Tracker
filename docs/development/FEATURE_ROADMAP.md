# Feature Roadmap Status

This file is intentionally kept as a compatibility pointer.

The old long-form roadmap format drifted from the real implementation state and release history, so it is no longer maintained as a source of truth.

## Source Of Truth

Use these locations instead:

- `specs/` for planned and in-progress work
- `docs/features/` for implemented feature behavior
- `CHANGELOG.md` for released changes
- `docs/TECH-DEBT.md` for engineering backlog and refactoring priorities

## Maintenance Rule

Do not add new feature status entries here.

If a roadmap-style summary is needed in the future, create a short-lived planning document that links to current specs and avoids duplicating implementation detail.
